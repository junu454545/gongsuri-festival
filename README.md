# 공수리마을 주막할매축제

강원특별자치도 양구군 공수리의 주막할매축제를 소개하고, 사진·영상·보도자료·운영 문서를 연도별로 모으는 웹사이트입니다.

- [축제 홈페이지](https://gongsuri-festival.co.kr/)
- [GitHub 저장소](https://github.com/junu454545/gongsuri-festival)
- [공수리마을 공식 블로그](https://m.blog.naver.com/gongsurimaeul)

## 프로젝트 목적

방문객에게 축제와 체험 프로그램, 이용 방법, 행사장 위치를 안내하고 공수리마을과 주막할매축제의 이야기를 전합니다. 흩어진 축제 자료를 모아 보존하며, 운영자는 GitHub에서 자료를 관리합니다.

## 2026년 축제 정보

| 항목 | 내용 |
|---|---|
| 행사명 | 2026 공수리마을 주막할매축제 |
| 일시 | 2026년 10월 10일 토요일, 11:00~17:00 |
| 장소 | 강원특별자치도 양구군 양구읍 공수리, 공수대교 근처 정자 일대 |
| 문의처·주최 및 주관 | 공수리 주막거리마을 |

2026년 행사는 종료됐습니다. 현재 홈페이지에는 당시 안내와 기록을 담고 있으며, 메인의 방문 유도 문구는 추후 정리가 필요합니다.

## 주요 기능

### 메인과 축제 소개

- 축제 일러스트, 행사 일정, 공식 포스터와 공식 블로그 연결
- 공수리 마을 소개, 축제 배경 이야기, 2023~2026년 역사와 연도별 사진 미리보기, 이장님 인사말
- 입장 팔찌·체험 참여·현장 운영 안내
- 구글 지도 삽입과 네이버지도·카카오맵·구글맵 외부 링크
- 공지사항·보도자료·갤러리·통계별 최신 자료 미리보기

### 부스 안내

놀이·체험·먹거리·판매·이용 안내로 분류한 안내 이미지를 제공합니다. 분류별 목록, 안내문 확대·원본 열기·이전 및 다음 이동을 지원합니다. 키보드 방향키 이동과 Esc 닫기도 사용할 수 있습니다.

### 자료실

| 구분 | 내용 |
|---|---|
| 공지사항 | 부스현황·배 운행시간표, 미리보기 이미지와 첨부 PDF |
| 보도자료 | 기사·방송 및 영상·공식 기록·기획 및 운영 자료 |
| 갤러리 | 축제 사진과 동영상 |
| 통계 | 결과요약·만족도 분석보고서 PDF, 설문분석집·조사 응답 엑셀 |

보도자료·갤러리·통계에는 연도 제목과 필터를 표시합니다. 보도자료는 출처와 원문·영상으로 연결하고, 갤러리는 사진 원본 열기와 업로드된 동영상 재생을 제공합니다. 공지 제목을 누르면 본문과 첨부자료가 펼쳐집니다.

통계는 운영자가 등록한 자료입니다. 방문자 수와 공지 조회수를 자동 집계하는 기능은 없습니다.

### 디자인과 사용성

- 화이트 배경과 파스텔 브라운 포인트
- PC·태블릿·모바일에 대응하는 반응형 배치
- 상단 메뉴의 현재 영역 표시와 화면 오른쪽 아래 맨 위로 이동 버튼
- 본문 바로가기, 키보드 초점 표시와 이미지 대체 설명

기존 작업에서 브라우저의 모바일 화면 재현과 주요 동작을 점검했습니다. 실제 휴대폰 기기별 검증은 추가 점검 항목입니다.

## 파일 구성

HTML, CSS, JavaScript로 제작한 정적 사이트이며, 자료실 목록은 JSON으로 관리합니다. 별도의 서버나 데이터베이스는 사용하지 않습니다.

| 파일·폴더 | 역할 |
|---|---|
| `index.html` | 메인 홈페이지와 부스 카드 |
| `about.html` | 마을·축제 소개 |
| `board.html`, `board.js` | 자료실 화면·연도 필터·공지 펼치기 |
| `board.json` | 공지사항·보도자료·갤러리·통계 목록 |
| `archive-preview.js` | 메인의 최근 자료 미리보기 |
| `booths.js`, `booths.css` | 부스 필터와 안내문 확대 보기 |
| `booths.json` | 부스 목록 참고 데이터. 현재 화면에서 직접 불러오지 않음 |
| `style.css`, `layout.css`, `ui.css`, `main-hero.css` | 디자인과 반응형 배치 |
| `layout.js` | 메뉴와 스크롤 관련 동작 |
| `assets/` | 화면용 이미지와 미리보기 |
| `사진/` | 사진·영상·부스 안내 원본 |
| `files/` | 공개 다운로드 자료 |
| `.github/workflows/` | GitHub Pages 자동 배포 설정 |
| `CNAME` | 사용자 지정 도메인 |
| `netlify.toml` | 이전 배포 과정에서 사용한 Netlify 설정 |

현재 자료 등록은 `board.json`을 기준으로 합니다.

## 자료 관리

1. 사진·영상·문서를 GitHub 저장소에 업로드합니다.
2. `board.json`의 `notices`, `press`, `photos`, `statistics` 중 해당 배열에 항목을 추가합니다.
3. 변경사항을 `main`에 반영합니다.
4. GitHub Actions 배포 완료 후 실제 자료실과 다운로드를 확인합니다.

사이트 안에서 로그인하거나 직접 업로드하는 관리자 기능은 없습니다. 관리 권한은 GitHub 저장소 권한으로 관리합니다.

부스 카드는 `index.html`에 작성돼 있습니다. `booths.json`만 수정하면 화면에 반영되지 않으므로 카드와 이미지 경로도 함께 수정해야 합니다.

예시와 수정·삭제 절차는 [자료실 관리 방법](자료실-관리방법.md)을 참고하세요.

## 로컬 확인과 배포

자료실은 파일을 더블클릭하는 대신 로컬 웹 서버로 확인합니다. Python이 설치된 환경에서는 저장소 루트에서 다음 명령을 실행한 뒤 `http://localhost:8000`을 엽니다.

```sh
python -m http.server 8000
```

`main` 변경 시 GitHub Actions가 Git에 등록된 정적 파일을 GitHub Pages에 게시합니다. 별도 빌드 과정은 없으며, 사용자 지정 도메인은 `gongsuri-festival.co.kr`입니다. `work/`, `outputs/`는 Git 추적에서 제외됩니다. 로컬에만 있는 새 파일은 배포되지 않습니다.
