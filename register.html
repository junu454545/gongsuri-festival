관리자용
자료 등록은 GitHub에서 진행합니다.

저장소 쓰기 권한이 있는 관리자가 로그인 후 파일과 목록을 저장합니다. 이 페이지는 등록 방법을 안내하며, 방문자는 자료실에서 파일을 내려받을 수 있습니다.

01

공개할 파일을 올려주세요

안내문, 포스터, 행사 사진 등을 준비합니다.

아래 버튼으로 저장소를 열고 files 폴더로 들어갑니다. Add file → Upload files로 파일을 올린 뒤 Commit changes로 저장해주세요.

작업 중인 브랜치를 사용한다면 파일과 목록을 같은 브랜치에 등록해주세요. files 폴더와 resources.json이 아직 없다면 먼저 자료실 변경사항을 반영해야 합니다.

파일명은 festival-guide.pdf처럼 영문·숫자·하이픈을 권장합니다.

GitHub에서 파일 등록 ↗
02

자료 목록에 추가해주세요

제목, 날짜, 파일 위치를 입력합니다.

저장소의 resources.json을 열고 연필 모양 편집 버튼을 누릅니다. 아래 예시를 참고해 항목을 추가한 뒤 저장해주세요. 파일 위치는 실제 올린 파일명과 같아야 합니다.

[
  {
    "title": "축제 안내문",
    "date": "2026-10-30",
    "description": "행사 일정과 이용 안내입니다.",
    "file": "files/festival-guide.pdf"
  }
]

예시는 실제 파일을 올린 뒤 사용하세요. 여러 항목은 쉼표로 구분하고 마지막 항목 뒤에는 쉼표를 넣지 않습니다. 설명은 생략할 수 있으며 최신 날짜 순으로 표시됩니다.

GitHub에서 자료 목록 관리 ↗
03

자료실에서 확인해주세요

운영 브랜치 반영과 배포가 끝나면 공개됩니다.

공동작업용 브랜치의 변경은 운영 브랜치에 합쳐져야 홈페이지에 반영됩니다. GitHub Pages 배포가 끝나면 제목·날짜와 파일 다운로드를 확인해주세요.

확인해주세요

  • 01
    관리자 계정으로 등록

    등록과 수정 권한은 GitHub에서 관리합니다.

  • 02
    공개 가능한 자료만

    방문자는 로그인 없이 파일을 내려받을 수 있습니다. 사진의 공개 동의도 확인해주세요.

  • 03
    수정과 삭제

    resources.json의 항목을 수정하거나 제거합니다. 목록에서만 지우면 기존 파일 주소로는 계속 접근할 수 있으므로 필요하면 파일도 삭제해주세요.

홈페이지에서 바로 업로드하지 않습니다.

파일 선택·임시 저장 대신 GitHub에서 파일과 목록을 저장합니다.
